# G.PLOT-studio
Offline-first Android &amp; Web CAM suite for 2D CNC plotters, laser engravers &amp; GRBL/FluidNC/grblHAL/Marlin machines. Convert PNG/JPG/SVG/DXF/PDF or text to G-Code, preview with a 2D simulator, and stream directly via USB OTG, Web Serial, Bluetooth, or Wi-Fi TCP. Supports 8 controllers &amp; 7 languages.
